About one.css

one.css is designed to provide a premium, modern look with minimal effort. It leverages semantic HTML to create high-quality interfaces without the need for complex class name systems.

Why one.css?

  • Classless by default: Style standard HTML elements directly.
  • Dark Mode & Themes: Built-in light dark support. Change the whole color scheme by adding .theme-<name> to the <html> element (e.g., .theme-blue); available names are listed in the sidebar's Theme Color select.
  • Premium Aesthetics: Modern typography (Inter), smooth transitions, and a curated color palette.
  • Responsive: A robust grid system that handles sidebar overlays and centered layouts.
  • 256 Icons Included: Hand-picked Material Symbols, covering 99% of web tool use cases.

Installation

Set up one.css in your project:

  1. Download the bundle (ZIP).
  2. Add the stylesheet to your <head>: 
    <link rel="stylesheet" type="text/css" href="one.css">
  3. Place the Inter and Material Symbols fonts in the same folder as one.css.
  4. Optional: Add one.js for toasts, dialogs, async storage, and Esc closing the mobile sidebar: 
    <script src="one.js"></script>

Semantic Power

By using elements like <header> , <main>, <aside>, and <footer>, you get a full-featured app layout for free. Form elements like <fieldset> and <legend> are beautifully styled, and advanced components like <dialog> and <progress> follow a consistent design language.

Accessible Icons

Icons are icon-font ligatures, so screen readers announce their raw text (more_vert becomes "more underscore vert"). Hide decorative icons with <span class="sym" aria-hidden="true">more_vert</span>, and name icon-only buttons via aria-label: <button class="btn-sym" aria-label="Add row">add</button>.

Announcements

A live region (role="status", aria-live="polite") whose message is already visible elsewhere — a readout, the footer, a toast — gets class="sr-only": announced, but never printed twice on the page. hidden would silence the announcement instead.

Typography

Body copy is rendered in Inter (variable font, loaded locally from Inter-VariableFont_opsz,wght.ttf), with a full system-font fallback chain. Font smoothing (-webkit-font-smoothing: antialiased / -moz-osx-font-smoothing: grayscale) is applied globally so text looks crisp on every platform, including macOS retina screens.

Scroll Shadows

Use scroll shadow utility classes to indicate scrollable content boundaries. These utilities dynamically reveal top/bottom or left/right shadows as content overflows and scrolls.

Horizontal Scroll Shadows

Apply the .scroll-shadow-x class to a container. By default, it expects a background matching var(--surface-container). For containers with other background colors, define the --scroll-shadow-bg custom property.

Vertical Scroll Shadows

Apply the .scroll-shadow-y class to a container. By default, it expects a background matching var(--surface-container-highest) (like dialogs). To customize, define the --scroll-shadow-bg custom property to match your container's background.

Tooltips

Add a tooltip to any element by simply adding the data-tooltip="Your text here" attribute. Thanks to modern CSS anchor positioning, tooltips automatically adapt their position to always remain visible on-screen and close to their source.

Hover this text

To display a tooltip exclusively on mobile viewports (e.g., when text labels are hidden via .hide-mobile and only icons remain), use data-tooltip-mobile="Your text". This tooltip automatically disables itself on desktop screens (900px and up).

Button Press Feedback

Momentarily add the .feedback-active class to a button to signal that a click did more than register — it actually changed state (e.g. after a successful copy). Remove it again after a few hundred milliseconds.

btn.classList.add("feedback-active");

JS Storage API

one.storage provides a lightweight Promise-based IndexedDB key-value wrapper (get, set, del, clear, keys). It serves as an asynchronous replacement for localStorage to bypass its 5 MB limit and avoid blocking the main UI thread when persisting larger text buffers or app data.

await one.storage.set("key", val); / await one.storage.get("key");
