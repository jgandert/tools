A presentation is a ZIP

            

                
Keep slides.md and slides.css together at the ZIP root (a single enclosing folder also works). Include any images or other assets they reference. Open a ZIP or drop it onto the preview; Download ZIP preserves both editor files and the other assets.

                
Writing slides

                
Separate slides with a line containing ---. Separators inside fenced code blocks are ignored. Each slide needs a # Heading. Use ==highlight== for emphasis and <!-- notes --> before speaker notes.

                
Optional first-line metadata: <!-- layout: cover | section: Intro | footer: Source | lang: en -->. Layouts: generic, cover, caveat, metric, metric-pie, quality and result. Additional metadata: logo, logo-alt, stat-label, unit: number, unit: decimal or unit: duration.

                
Styling slides

                
The slide document has a fixed 1600 × 900 canvas. Target .slide, .slide-title, .slide-top, .slide-footer and the layout classes. Change --paper, --ink, --accent, --display and --body on :root. Your stylesheet is applied after the neutral slide defaults and cannot style this editor.

                
Relative url(...) references and Markdown images resolve to files in the ZIP. Scripts, remote images, external stylesheets and CSS imports are blocked in slides. ZIP fonts are embedded into both slide documents as data URLs; the editable CSS keeps its relative paths. Fonts and images may also use authored data URLs. The Fonts & assets report distinguishes decoding failures, missing paths, local-only sources and unreferenced font files. Extra files are retained when downloading.

                
Keyboard

                
← / → or Space: navigate. Home / End: first / last. 1–9: jump. F: full screen. O: overview. N: notes. E: editors. K: confetti (disabled when reduced motion is preferred). ?: help. Ctrl/⌘ + S: download ZIP. Navigation shortcuts do not run while typing.

                
Print renders all slides, not just the current slide. Invalid Markdown leaves the last valid preview intact; editor text is still saved and exportable. Browsers ignore invalid CSS declarations. Download a ZIP to keep a durable copy of your work.
