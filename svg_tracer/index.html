                How tracing works
                
Best for flat-color artwork such as logos and diagrams. Shared borders are fitted once, so neighboring regions use matching geometry. Outlines remain filled regions.

                
Auto color counts and shape recognition are heuristic. Set a known color count if shadows or small details are misread. Downsampling can erase narrow features before tracing.

                
Gradients, translucent fills, text recovery, and hidden objects are not supported. Separate fills may show antialias seams in some SVG viewers; no overlapping strokes are added to hide them.
