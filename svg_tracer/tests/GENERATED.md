# Generated campaign artwork

These original images were made with the built-in image-generation tool without reference images. They are stress inputs, not vector ground truth: shading, antialiasing, and unintended color variation remain in the bitmaps despite the flat-fill requests. Pixel error and recovered paint counts cannot establish semantic correctness. The transparent source retains the tool's alpha channel.
