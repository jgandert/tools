Set up the table

Build the shared supply first, then prepare each player area. Guide adjusts quantities and two-player rules automatically.

Step 1 of 5 4 players

Build shared supply

Place four shared groups within everyone's reach.

  • Put all 55 double-sided game tiles in the bag.
  • Place all unclaimed dice nearby as dice supply.
  • Lay out five phase tiles in numeric order, inactive side up.
  • Prepare 48 VP in 1- and 5-point chips: 12 per player.
  • Set every 10-point chip aside. Return unused 1- and 5-point chips to the box.

Set-aside 10-point chips only record points after the initial VP chip pool runs out. Emptying that initial pool still triggers game end.

Prepare player stations

Give every player the same five-part kit.

  • One dice cup
  • One player mat
  • One Galactic Credit marker, placed at $1
  • One player screen
  • One phase strip, kept behind the player screen

Return unused player components to the box.

Create starting empires

Give each player one random faction tile and one random home world. Return unused starting tiles to the box.

  • Place both face up beside the player mat; together they form the starting tableau.
  • The wide faction tile counts as 2 tile squares.
  • The home world tile counts as 1 tile square.

Every player begins at 3 of 12 tableau squares needed to trigger game end.

Seed construction zones

Each player draws two tiles from the bag. Every tile has a development on one side and a world on the other.

  • Place one tile development-side up on left stack.
  • Place other tile world-side up on right stack.
  • For the first game, place the lowest-cost development on the left and the lowest-cost world on the right.
  • Choose either side of each tile, then place one in each stack.

Do not put both tiles in the same stack.

Place starting dice

The fixed baseline uses five Home (white) dice per player. Starting tiles can grant more dice in different locations.

  • Put 3 Home dice in the dice cup.
  • Put 2 Home dice in the Citizenry.
  • Take every die granted by worlds in the starting tableau. Follow each icon: dice cup, Citizenry, or good on a world.
  • Take nothing from the unbuilt world in the construction zone.
Starting tile exceptions

The Doomed World home world grants no starting die; set its owner's marker to $8. The Destroyed Colony faction tile shows two worlds; take the listed starting dice from both.

Table is ready

4 players can begin with 48 VP in the initial pool.

Keep screens up during Roll and Assign. Play simultaneously; if a phase needs strict timing, resolve it clockwise, starting with the player whose faction tile has the lowest number.

Learn first round

Learn a round

All players perform each step together. Only phases selected this round occur.

Roll behind screens

Every die in the dice cup is a worker for this round. Roll all of them behind the player screen and keep results hidden.

Dice outside the dice cup are not rolled: Citizenry, goods, and workers in the construction zone stay where they are.

Assign and choose one phase

  1. Place each worker below the column matching its rolled face. Wild faces may enter any column.
  2. Move exactly one worker onto the phase strip to select a phase. Ignore its face; this die still works in the selected phase.
  3. After selecting a phase, apply Reassign powers. Each can be used at most once per round; a power is optional only when its text says "may."

Dictate: park any worker in the Dictate area to move a different worker to another column. The parked die returns to the dice cup after reveal.

Reveal selected phases

Lift player screens together and announce selected phases. Flip matching phase tiles to the active side.

  • Return every Dictate die to its owner's dice cup.
  • Return workers assigned beneath inactive phases to the dice cup.
  • Leave workers under active phases for task resolution.

Two players: roll one spare Home (white) die. If its face names a phase neither player selected, activate that phase too. A wild face changes nothing; return the die to the shared supply.

Resolve active phases in order

Everyone acts simultaneously in phase I through V. Skip inactive phases. Use every assigned worker if a task is possible, one at a time.

  1. I · Explore Scout or gain Galactic Credits
  2. II · Develop Build technology
  3. III · Settle Complete worlds
  4. IV · Produce Place goods
  5. V · Ship Trade or consume

Dice completing tasks go to Citizenry. Dice left without a possible task return to the dice cup. Choosing a phase grants no separate bonus.

Manage empire

  1. Recruit. Spend 1 Galactic Credit per die to move as many dice as affordable from Citizenry to the dice cup. If Galactic Credits reach 0, move the marker back to $1 after recruiting.
  2. Recall. Optionally return developers, settlers, and goods directly to the dice cup for free. If the dice cup is empty after recruiting, recall at least one die.
  3. Reset. Turn all phase tiles inactive.
  4. Check end. Finish the game if the initial VP chip pool emptied or any tableau reached 12 tile squares.

Galactic Credits never exceed $10. If you cannot afford every die in Citizenry, choose which dice to recruit.

Rules reference

Open the rule you need. Development powers can change these defaults. Powers for an active phase can take effect even if you assigned no workers to it, and are mandatory unless their text says "may."

Assign and resolve

Workers, phase selection, and Reassign
  • Worker's column determines task; printed face only guides initial assignment.
  • Each player selects exactly one phase before using any Reassign power.
  • Selected die remains worker in chosen phase.
  • Each Reassign power can be used at most once per round. A power is optional only when its text says "may." Moved die need not show target phase.
  • Dictate spends one worker to reassign a different worker. The spent die returns to the dice cup at Reveal. Reassign powers cannot move dice already spent on Dictate.
I · Explore

For each explorer, choose one task when used:

Stock
Gain 2 Galactic Credits.
Scout
Optionally abandon any tiles from either construction zone stack, then draw one more tile than number abandoned. Choose a side for each drawn tile and place it under the matching stack. Return abandoned tiles to the bag after the phase.

Abandoning no tiles means drawing one. Workers already in the construction zone remain even if a stack becomes empty. If the bag runs out while drawing, return abandoned tiles to it and continue. If there still are not enough, choose sides for the tiles drawn so far and place them in your construction zone. Any player whose zone then holds at least 3 tiles, Scout included, must put 1 tile back in the bag. The Scout then finishes the draw.

II · Develop

Place developers one at a time on the top development. Apply every applicable cost reduction; these are mandatory. Even after reductions, at least 1 developer is needed to complete a tile. Once enough developers are on the tile to meet its cost, move it into the tableau and return the completing developers to Citizenry. Use any remaining developers on the next tile; several developments may finish in one phase.

Incomplete developers stay on their tile between rounds. If the stack is empty, excess developers return to the dice cup. If scouting or an Explore power completes a tile early, leave it on the stack until the next Develop phase is played. Then move it into the tableau, return the required developers to Citizenry, choosing which ones if there are extras, and put any extras on the next tile. Resolve a development's immediate effect when it enters the tableau. Follow the timing stated for each development power; Reassign powers are used during Assign.

III · Settle

Place settlers one at a time on the top world. Apply every applicable cost reduction; these are mandatory. Even after reductions, at least 1 settler is needed to finish a world. Once enough settlers are on the world to meet its cost, move it into the tableau, return the completing settlers to Citizenry, and apply its immediate effect once. Use any remaining settlers on the next world; several worlds may finish in one phase.

If scouting or an Explore power completes a world early, leave it on the stack until the next Settle phase is played. Then move it into the tableau, return the required settlers to Citizenry, choosing which ones if there are extras, and put any extras on the next world. If no world remains, excess settlers return to the dice cup. The tile's icons show its dice and any extra credits or starting good. If an effect removes a die, return any of your dice from any location to the shared supply; if it removes the die that selected a phase, that phase still occurs.

IV · Produce

Each producer becomes a good on one non-gray tableau world. Any die color can produce on any such world. Normally a world holds one good; Galactic Reserves raises this to two. Unused producers return to the dice cup.

V · Ship

Pair each shipper with one good, then choose Trade or Consume. Both dice go to their owner's Citizenry.

Consume: gain 1 VP, +1 if good die color matches world, and +1 if shipper die color matches world. Purple Consumption dice match every color for these bonuses only.

Economy and ending

Recruit, Recall, and Galactic Credit limits
  • Recruit as many Citizenry dice as affordable, at 1 Galactic Credit each.
  • If recruitment leaves 0 Galactic Credits, reset the marker to $1 afterward.
  • Recall construction zone workers or goods to the dice cup for free only during Manage Empire. Starting goods cannot be recalled before the first Roll.
  • If the dice cup is empty after recruiting, recall at least one die.
  • Galactic Credits cap at $10; excess is lost.
Game end and scoring

Finish the current round when the initial VP chip pool has emptied or any player reaches at least 12 tableau squares. Players may finish above 12.

Score VP chips, the printed cost of every tableau tile (both values on the faction tile), and bonuses from 6-cost developments. For group-based bonuses, round the number of groups up before multiplying by the bonus: 7 qualifying dice at 2 VP per 3 dice score 6 VP. Construction-zone tiles do not score.

Tied players add dice in the dice cup and current Galactic Credits. The highest combined total wins; a remaining tie is shared.

Frequently missed rules
  • Play is simultaneous; everyone participates in every active phase.
  • Tasks resolve one worker at a time. No advance declaration for Scout, Stock, Trade, or Consume.
  • Completed-task dice go to Citizenry. Inactive-phase and unusable dice go to dice cup.
  • Develop and Settle can each complete multiple tiles in one phase.
  • Produce comes before Ship.
  • Trade uses world color. Consume bonuses use dice colors; wild face adds nothing.
  • The starting faction tile plus home world tile already count as 3 tableau squares.
  • Construction-zone tiles do not score.
